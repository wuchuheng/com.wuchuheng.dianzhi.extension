# 点知 Chrome 应用商店说明（简体中文）

## 概述

【点知】是一款基于上下文的 AI 英文划词阅读助手。

阅读英文网页时，选中一个单词、短语或句子，点知会结合它在原文中的上下文，给出更贴合当前语境的解释。你无需复制文本、切换标签页，也无需重新向 AI 描述这段话的背景。

点知关心的不只是“这个词通常怎么翻译”，而是“它在这句话里究竟是什么意思”。

## 核心特点

### 🎯 结合上下文，解释当前含义

- 读取选中内容附近的有界上下文，帮助 AI 判断单词或短语在原文中的具体含义。
- 区分同一个词在不同句子、领域和表达中的意思。
- 保留页面中的选区高亮，解释与原文可以直接对照。

### ⚡ 划词即懂，不打断阅读

- 在 HTTPS 网页中选中英文，松开鼠标即可在选区附近查看结果。
- 浮层会跟随选区定位，无需离开当前网页。
- 支持紧凑卡片和对话模式，简单问题就地查看，需要时再继续追问。

### 🧠 五种内置工具，从不同角度理解原文

- **语境**：解释选中内容在当前原文中的含义和语气。
- **同义词**：给出符合当前语境的替换表达并说明差异。
- **翻译**：根据上下文提供自然的中文翻译。
- **词典**：查看单词的常用释义与相关信息。
- **英英释义**：用英文理解英文，减少对直译的依赖。

内置工具可以重命名、调整顺序或停用。你也可以创建自定义工具，通过自己的提示词定义新的查询方式。

### 💬 从网页浮层到 Chrome 侧边栏

- 将当前会话移交到 Chrome 原生侧边栏，腾出网页阅读空间。
- 侧边栏延续当前选区、工具和对话，无需重新开始。
- 可以继续提问、切换工具、停止生成或重试回复。

### ⌨️ 快捷键与个性化阅读

- 快速切换上一个或下一个工具。
- 使用数字快捷键直接切换到指定工具。
- 在卡片与对话模式、紧凑与宽屏模式之间切换。
- 支持自定义交互快捷键、上下文长度和工具提示词。

### 🔌 使用你自己的 AI 服务

- 支持 OpenAI 兼容的流式 `/chat/completions` 服务。
- 可配置 API 地址、API Key、模型、温度和推理选项。
- 提供连接测试，方便在开始阅读前确认服务是否可用。

点知不捆绑特定 AI 平台。你需要自行准备可用的 OpenAI 兼容服务、密钥和模型。

## 数据与隐私说明

- 对话和消息保存在当前 Chrome 扩展环境的本地 OPFS SQLite 数据库中。
- API Key 保存在 Chrome 扩展设置中，不会写入对话数据库或应用日志。
- 为了生成回复，选中的英文、相关上下文和对话内容会发送到你自行配置的 AI 服务。具体数据处理方式取决于该服务提供方的隐私政策。
- 点知不会把 API Key 或选中的原文写入应用日志。

## 三步开始使用

1. 安装点知后，打开“设置”并配置 OpenAI 兼容的 API 地址、API Key 和模型。
2. 打开任意 HTTPS 英文网页，选中想要理解的单词、短语或句子。
3. 在选区旁查看结果，切换理解工具，或将当前对话移交到 Chrome 侧边栏继续追问。

## 适合谁使用

- 经常阅读英文技术文档的开发者。
- 需要查阅英文论文、新闻和专业资料的用户。
- 想通过真实语境学习词义、搭配和英文表达的学习者。
- 希望减少复制、粘贴和切换 AI 聊天页面的重度阅读用户。

点知的目标很简单：让你在不离开原文的情况下，更准确地理解正在阅读的英文。
